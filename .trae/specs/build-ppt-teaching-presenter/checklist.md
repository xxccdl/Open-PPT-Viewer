# Checklist

> 验证环境：Windows 10 1709+ / 4GB RAM / 机械硬盘 / 双核 CPU 教室老机（或等效降配虚拟机）。
> 主观项（保真度、手感）由人工评审；客观项由 `scripts/` 下的性能脚本输出数据判定。

## 一、启动与打开性能

- [ ] 冷启动（进程启动 → 窗口可见）实测 ≤ 400ms，且过程中无 splash 窗口
- [ ] 双击 100 页 `.pptx` 文件 → 第 1 页可交互 ≤ 1.2s
- [ ] 双击 `.pptx` 直接进入课件第 1 页，未出现起始页/欢迎页
- [ ] 打开 100 页课件时，实际磁盘读取量 ≤ 课件体积的 30%
- [ ] 打开 100 页含图课件时，常驻内存峰值 ≤ 350MB
- [ ] 冷启动数据被写入基准日志，可与 WPS 对比

## 二、惰性解析与渲染调度

- [x] 打开 100 页课件时，仅完成第 1 页解析与渲染，第 2 页在后台预热
  - 注：解析层已验证（打开时不读任何 slideN.xml）；「第 2 页后台预热」属渲染调度，见 Task 6
- [x] 打开阶段未解压/解析第 3 页及之后的幻灯片 XML（由 `was_part_read` 逐部件断言验证）
- [x] 未被渲染页所引用的媒体流未被读取（端到端测试断言打开阶段不读 `ppt/media/*`）
- [ ] 具备内存 LRU（默认上界 8 页光栅位图）与磁盘缓存两级缓存
- [ ] 同一课件第二次打开时，缩略图与已渲染页命中磁盘缓存
- [ ] 连续快速翻页时，过期渲染任务被取消，未出现队头阻塞
- [ ] 回翻到已访问过的幻灯片时从缓存命中并即刻呈现
- [x] 版式/母版的继承链按版式缓存复用（同一版式的多页只解析一次主题与母版）

## 三、翻页与呈现

- [ ] 翻到已预热页 ≤ 16ms
- [ ] 翻到未预热页 ≤ 120ms
- [ ] 新帧就绪前持续显示上一帧，全程无白屏、无半渲染画面
- [ ] 帧切换有短促淡入过渡，且不阻塞输入
- [ ] 连续快速翻页时主线程无 long task 阻塞

## 四、PPTX 渲染保真度

- [x] 主题/母版/版式三级继承（颜色、字体、占位符）正确生效
- [x] 纯色/渐变/图案/图片填充渲染正确
- [x] 形状轮廓（宽度、虚线、端点、连接）、圆角与自定义几何路径渲染正确
- [x] 直线、曲线、自由曲线渲染正确
- [x] 组合形状与嵌套变换正确
- [x] 文本框渲染正确：自动换行、内边距、垂直对齐、项目符号与编号
- [x] 表格渲染正确：列宽、行高、合并单元格、边框、底纹
  - [x] 行高按内容自动长高（`a:tr/@h` 在 PowerPoint 里是**最小值**）：
        装不下时长高，而不是让单元格文字压到下一行上
- [x] 图片渲染正确：裁剪、旋转、翻转、本地与链接图片
- [ ] 图片效果（阴影、发光、柔化边缘）渲染正确
- [x] 超链接与动作按钮被识别且可点击
- [x] 动画：按课件作者设定的点击顺序逐步出现/消失，含项目符号逐条弹出；
      放映时「先播完本页动画，最后一下才翻页」，回翻时动画已播完的页直接给全貌
  - [x] 飞入/淡入/擦除/缩放进出等**过程**按作者设的时长与方向逐帧播放
        （离线合成核对：`第 3 页` 红 C 从画面外飞入、播完正好落进括号）
  - [x] 强调动画（放大/缩小/旋转）会播，且播完**停在**那个状态不再弹回
  - [x] 触发器动画：点作者指定的形状才播它那一步，点别处不消耗这一步
  - 边界：文字变色（`p:animClr`）与字体样式类强调仍降级为「占一步空点击」并告警
- [x] 幻灯片转场：按 `p:transition` 播放推入/擦除/覆盖/揭开/拆分/缩放/百叶窗/
      棋盘/梳理/条带/轮辐/圆形/菱形/十字/楔形/双开门等，时长与方向都照课件设的来
  - 三维类转场（`cube`/`vortex`/`morph`）退化为淡入，但解析层保留原名便于诊断
  - 作者的「自动前进」（`advTm`）与「取消点击前进」（`advClick="0"`）也被遵守
- [x] 上下标（`a:rPr/@baseline`）正确抬高/压低并缩小
- [x] 内嵌视频/音频：封页图正确显示，点击后原位播放（进度/音量/全屏可用），
      不播放时不遮挡画面；拿笔时笔迹可落在视频画面之上
  - 注：视频/音频本体必须在真实课件上验收解码兼容性（H.264/AAC 之外编码需另测）
- [ ] 页码/日期/页脚占位符渲染正确
- [x] 演讲者备注被正确提取并可在控制台显示
- [x] SmartArt/图表/嵌入对象不报错、不空白，降级为占位 + 文本，并记录降级日志
- [x] 图表渲染：柱状/条形/折线/饼图/圆环/散点按 `chartN.xml` 的数据正确绘制，
      含标题、图例、坐标轴刻度、网格线、数据标签与主题配色；
      不支持的图表类型（面积/雷达/股价/曲面）降级为占位并给出中文原因
  - 注：图表仅还原**静态呈现**，不实现数据编辑与动画
- [x] 缺失字体时按回退链替代（中文回退 CJK 字体），无豆腐块、无文字裁切
- [x] 中英混排断行符合中文排版习惯：行首无闭标点、行尾无开标点、数字与英文单词不被拆断
- [x] 行高与段落间距与课件设定一致
- [ ] 样本语料集整体保真度人工评审通过，无素材丢失
- [ ] 对照 WPS 打开同一课件，版式与配色基本一致

## 五、文本排版引擎

- [x] 系统字体索引建立成功，字体名 → 系统字体映射与回退链生效
- [x] 字形度量与字号换算正确，度量缓存生效
- [x] 文本整形（连字、字距调整）正确
- [x] `normAutofit`/`spAutoFit` 字号自适应正确（长文本不溢出、不裁切）
- [x] 竖排文本布局可用
- [x] 文本布局快照测试全部通过（含中英混排、标点行首行尾、长英文单词、超大字号自适应）
- [x] 主题字体引用（`+mj-lt` / `+mn-ea`）在解析阶段解析为具体字体名
- [x] 文本按字形轮廓矢量绘制，任意缩放下清晰（非位图字形缓存）

## 六、触屏与手写笔适配

- [ ] 鼠标、手写笔、手指三种输入均可完成翻页、标注、缩放、工具栏点击
- [ ] 手写笔书写时笔迹跟手延迟实测 ≤ 30ms
- [ ] 手写笔压感生效：用力线粗、轻触线细
- [ ] 笔迹平滑无折线感，具备笔锋收尾
- [ ] 手写笔活跃期间，手掌接触不产生笔迹、不触发平移/缩放
- [ ] 双指捏合缩放正常，且全程不产生任何笔迹
- [ ] 单指绘制与双指缩放手势分离正确，并提供「单指为画笔/单指为平移」模式开关
- [ ] 所有可点击控件触摸热区 ≥ 44×44 逻辑像素，相邻控件不易误触
- [ ] 高 DPI 触控屏下坐标映射正确，无偏移

## 七、标注功能

- [ ] 撤销/重做支持 ≥50 步，按笔迹粒度工作
- [ ] 可清空当前页标注
- [ ] 标注以幻灯片索引为键绑定，翻页往返后保持不丢失
- [ ] 页面缩放/平移后标注仍锚定在幻灯片同一相对位置
- [ ] 关闭窗口时若有未保存标注会提示「保存/不保存/取消」
- [ ] 保存的标注以旁挂文件存放，原课件未被修改

## 十一、性能档位与容错

- [ ] 启动时完成 CPU 核心数、可用内存、GPU 与驱动探测

- [ ] 端到端性能脚本可输出与 WPS 的对比报告
